\subsection{Important Design Decisions}

\textbf{Why No OTP Login?}

OTP-based authentication via SMS was intentionally removed to avoid ongoing Twilio costs. Each SMS costs money, and for a golf app, username + password authentication is sufficient and more cost-effective. This decision:
\begin{itemize}
    \item Eliminates monthly SMS costs
    \item Simplifies the authentication flow
    \item Maintains security with bcrypt password hashing
    \item Still offers magic link as passwordless alternative
\end{itemize}

\textbf{Magic Link Status:}

Magic link authentication is fully functional but currently outputs links to console instead of sending emails. This is because:
\begin{itemize}
    \item SendGrid integration not configured yet
    \item Console mode perfect for development/testing
    \item Can be enabled for production by adding SendGrid API key
    \item No code changes needed, just configuration
\end{itemize}
