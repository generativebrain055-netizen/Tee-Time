# Signup Screen - User Guide

## How to Sign Up

### Step 1: Enter Your Information

1. **First Name** - Enter your first name (e.g., "John")
2. **Last Name** - Enter your last name (e.g., "Doe")
3. **Username** - Choose a unique username (minimum 3 characters)
4. **Phone Number** - Select your country code and enter your phone number
5. **Handicap** - (Optional) Enter your golf handicap
6. **Password** - Create a password (minimum 6 characters)

### Step 2: Select Country Code

**To select your country:**
1. Tap the country code button (shows flag and code like "🇺🇸 +1")
2. A modal will open with all countries
3. **Search for your country:**
   - Type country name (e.g., "Canada")
   - Or type country code (e.g., "+44")
   - Results filter as you type
4. Tap your country to select it
5. Modal closes automatically

**Tips:**
- Countries are listed alphabetically
- Use search to find your country quickly
- Only one country can be selected at a time
- Selected country shows a green checkmark (✓)

### Step 3: Request OTP

1. Review your information
2. Tap "Send OTP" button
3. Wait for SMS with 6-digit code
4. **Note:** In development mode, check server console for OTP

### Step 4: Verify OTP

1. Enter the 6-digit code you received
2. You have 60 seconds to enter the code
3. Tap "Verify & Continue"
4. Your account will be created automatically

**If OTP expires:**
- You'll see: "⚠️ OTP expired. Please request a new one."
- Tap "Change phone number" to go back
- Request a new OTP

**If OTP is incorrect:**
- You'll see: "The OTP you entered is incorrect. Please try again."
- Try entering the code again
- You have 5 attempts before needing a new OTP

### Step 5: Welcome!

Once verified, you'll be logged in automatically and taken to the home screen.

## Common Issues & Solutions

### "Username already taken"
**Solution:** Choose a different username. Usernames must be unique.

### "Phone number already exists"
**Solution:** This number is already registered. Try logging in instead.

### "OTP expired"
**Solution:** Request a new OTP. Codes expire after 60 seconds.

### "Too many failed attempts"
**Solution:** Request a new OTP. You get 5 attempts per code.

### "Can't find my country"
**Solution:** 
- Use the search box at the top of the country list
- Type your country name or code
- Make sure spelling is correct

### Keyboard covering input fields
**Solution:** 
- Tap outside the keyboard to dismiss it
- Scroll up/down to see all fields
- The form automatically adjusts for the keyboard

## Tips for Best Experience

1. **Use a valid phone number** - You'll need it to receive OTP
2. **Choose a memorable username** - You'll use it to log in
3. **Create a strong password** - At least 6 characters
4. **Save your password** - You'll need it for future logins
5. **Check your phone** - OTP arrives via SMS
6. **Act quickly** - OTP expires in 60 seconds
