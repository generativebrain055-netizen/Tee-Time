# TTS Golf App - Requirements Document

## Project Overview
Mobile app for simplifying golf tee time coordination through automated invites, rosters, and communications.

## Target Audience
Casual to semi-serious male golfers who want to reduce coordination hassles.

## Technology Stack

### Mobile App
- Framework: React Native (iOS & Android)
- Push Notifications: Firebase Cloud Messaging

### Backend
- Runtime: Node.js
- Database: PostgreSQL
- SMS/Group Texting: Twilio
- Geolocation: Google Maps API
- Authentication: Magic link via phone number

### Admin Portal
- Web-based dashboard
- Framework: React (or similar)

### Deployment
- Cloud hosting (AWS/GCP/Azure)
- App Store & Google Play submissions

## Core Features - Phase I

### 1. Authentication & Onboarding
- Phone number-based registration
- Magic link authentication
- Profile setup (handicap, memberships, phone number)

### 2. User Profile
- Display: Social Rate, handicap, golf history, club memberships, phone number
- QR code generation for "Get Drafted"
- QR scanner for "Scan to Draft"
- Remove/block users functionality

### 3. Social Rate System
- Starting score: 100
- Accept invite: +2 points
- Decline >24hr notice: -1 point
- Cancel <24hr notice: -5 points
- No-show: -10 points
- Score range: 0-200 (capped)

### 4. Roster Management
- Create and manage personal roster
- Drag-and-drop ordering
- "On Deck" section for backup players
- Sort by: Yes Rate, Distance to course, Handicap, Club Membership
- View player profiles from roster

### 5. Invite Types

#### Roster Invite
- Sequential invite flow
- Configurable response window (1-24 hours)
- Visual indicators: green check (yes), arrow (waiting), decline icon, timeout indicator
- Auto-advance to next player on decline/timeout

#### First Come First Serve (FCFS)
- Broadcast to entire roster
- First responders join the group
- Fill spots based on group size

#### Open Invite
- Post to community board
- Geolocation filter (20-mile radius default)
- Visible to users within distance range

### 6. Send Invite Flow
- Select date/time
- Choose golf course (autocomplete with US golf course database)
- Set group size: Twosome, Threesome, or Foursome
- Select invite type
- Invite non-registered users via phone number
  - SMS sent: "You are invited to play golf by [Name], download the Tee Time App now to join"
  - Auto-link invite to profile upon registration

### 7. My Golf Dashboard
- Calendar view of upcoming tee times
- Quick access buttons:
  - Notifications
  - Send Invite
  - Roster
  - Waiver Wire

### 8. My Tee Times
- In-progress invites view
  - Status indicators (yes, waiting, declined, timeout)
  - Timer countdown for response windows
- Booked tee times view
- Historical tee times

### 9. Notifications System
Three categories:

#### Inbox
- Received invites
- Accept/decline actions
- Join requests

#### Outbox
- Sent invite status updates
- Player responses
- Group fill notifications

#### Community
- Waiver Wire posts from mutual roster members
- Open invite posts (geolocation-based)
- Ad placeholders (every third post)

Delivery methods:
- In-app notifications
- Push notifications (Firebase)
- SMS notifications (Twilio)

### 10. Waiver Wire
- Post week-of availability
- Time slots: Morning, Mid-day, Afternoon, Anytime
- Notify users with mutual roster connections
- View posts from roster members

### 11. Group Chat & Accountability
- Auto-create SMS group chat via Twilio when group fills
- Include all confirmed players
- Check-in functionality for no-show detection
- Social Rate updates based on attendance

### 12. Golf Course Database
- US golf courses with name and address
- Autocomplete search functionality
- Course details display

### 13. Community Features
- QR code friend additions
- Reciprocal add requests with accept/decline
- Notifications for new connection requests
- Profile viewing before accepting

- Firebase settings

## Non-Functional Requirements

### Performance
- App load time: <3 seconds
- Push notification delivery: <5 seconds
- Real-time updates for invite status changes

### Security
- Secure phone number authentication
- Data encryption in transit and at rest
- PCI compliance for future payment features
- User privacy controls

### Scalability
- Support 10,000+ concurrent users
- Handle 1,000+ simultaneous invites
- Database optimization for quick queries

### Usability
- Intuitive UI/UX
- Minimal clicks to complete actions
- Clear visual feedback
- Accessibility compliance

### Reliability
- 99.9% uptime
- Automated backups
- Error logging and monitoring
- Graceful degradation

## Development Approach
- Agile methodology with bi-weekly sprints
- UX/UI mockups in Figma (Weeks 1-2)
- Iterative client feedback cycles
- Internal QA testing
- 2 rounds of UAT (User Acceptance Testing)
